# Data

This folder contains documentation relating to the dataset used for the Ghana Financial Inclusion Analysis project.

## Data Source

The project will use a publicly available dataset relevant to financial inclusion in Ghana.

## Data Management

The original public dataset will be preserved separately where appropriate, while processed analytical data will be documented clearly.

## Data Protection

No confidential, personally identifiable, proprietary, or restricted datasets from Ghana Statistical Service, IPA Ghana, ISSER, SIA360 Ltd, or other organisations will be uploaded.

## Documentation

The data documentation will describe:

- Source
- Year
- Unit of analysis
- Key variables
- Sample characteristics
- Data limitations
- Processing steps
